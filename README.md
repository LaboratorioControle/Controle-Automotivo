# Controle-Automotivo
# Identificação e Simulação de Torque de Motor com Integração ESC

> ⚠️ Projeto em estágio inicial de desenvolvimento e testes.

## 📄 Sobre o projeto

Este repositório reúne o desenvolvimento de simulações voltadas para a modelagem do **torque de motores elétricos**, com o objetivo de futuramente integrar esse modelo ao loop de controle de um ESC.

A motivação do projeto surgiu da necessidade de identificar o modelo real do motor para permitir uma integração mais precisa com o sistema de controle de estabilidade.
